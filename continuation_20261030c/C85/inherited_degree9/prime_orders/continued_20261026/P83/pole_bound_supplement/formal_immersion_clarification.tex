\noindent\emph{Formal immersion matrix for order $83$.}
Choose a cusp with maximal multiplicity and translate it to the first
cusp by a diamond operator. If its multiplicity is $n_0$, every
other multiplicity is at most $\min(n_0,4)$, since the total is $9$.
The matrix consists of the nine operators $tT_1,\ldots,tT_9$ at
this first cusp and the four operators
$t\langle2\rangle^iT_1,\ldots,t\langle2\rangle^iT_4$ at each
of the other forty cusps. It is therefore a
$169\times61009$ binary matrix, where $61009=247^2$ is the
coordinate dimension of the endomorphism space.
Its row rank is $169$. Each normalized degree-$9$ jet configuration
selects nine distinct rows from this matrix, which are therefore
independent. The number of configurations is
\[
 \sum_{n_0=1}^{9}[z^{9-n_0}]
   (1+z+\cdots+z^{\min(n_0,4)})^{40}=134858144.
\]
The phrase ``complete relation kernel'' refers to the left kernel
of this $169\times61009$ matrix.
